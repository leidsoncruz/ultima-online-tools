Moonglow Loot Draw

Um sorteio transparente para o loot da dungeon.

1. Criar ou entrar numa sessão

Desligado

O anfitrião controla o sorteio. Os restantes jogadores entram com o código da sessão e acompanham as alterações em tempo real.

A ligação usa WebRTC ponto a ponto; é necessária uma pequena infraestrutura pública de sinalização para estabelecer a ligação inicial.

2. Jogadores

0 jogadores

A ordem da lista não determina o resultado; os jogadores serão baralhados no sorteio.

3. Baús

0 baús

Identifica os baús pela ordem em que foram numerados na dungeon.

4. Sorteio

À espera de participantes
—Ordem aleatória dos jogadores
—Baús por posição (1 → N)
—Distribuições reveladas

O sorteio baralha os jogadores. Depois, o baú nº 1 vai para o jogador na posição 1, o baú nº 2 para a posição 2, e assim sucessivamente. Para manter o sorteio justo, o anfitrião deve iniciar apenas quando as listas estiverem completas.

Feito para a comunidade de Ultima Online · Não é afiliado ao jogo nem ao servidor Auroria.
